# Design: Operations And Compliance Entrypoints

## User-Facing Entries

The mini program should expose:

- Privacy policy.
- User agreement.
- Feedback/problem report.
- Version notes or update log.

These entries should live in account/settings and not interrupt normal study flow.

## Admin Operations

The PC admin console should allow basic operations:

- Create or edit a simple announcement.
- View user feedback/problem reports.
- Maintain version notes.

MVP can keep these features simple with text fields and timestamps.

## Compliance Copy Guidance

Product copy should avoid:

- Promising guaranteed score or skill improvement.
- Encouraging excessive study.
- Money-like wording for slack minutes.
- Presenting AI output as professional advice.

AI copy should say generated plans are suggestions and can be edited. Rankings should be described as friendly motivation. Reminders should be user-authorized and configurable.

## Release Checklist

Before WeChat submission, verify:

- Privacy policy and user agreement are reachable.
- Phone number usage is disclosed.
- AI feature wording is conservative.
- Slack minutes are non-monetary.
- Reminder subscription copy explains user authorization.
- Account deletion/retention flow exists or is documented.
