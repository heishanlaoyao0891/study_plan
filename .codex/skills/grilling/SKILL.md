# Grilling

Interview the user relentlessly about every aspect of the subject until reaching a shared understanding. Walk down each branch of the decision tree, resolving dependencies between decisions one by one. For each question, provide a recommended answer.

Ask questions one at a time and wait for feedback before continuing. Asking multiple questions at once is bewildering.

If a fact can be found by exploring the environment, look it up rather than asking the user. The decisions belong to the user: put each one to them and wait for an answer.

Do not implement the plan until the user confirms that a shared understanding has been reached.
