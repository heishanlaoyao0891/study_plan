# Mini Program Critical Flow Checklist

- Login with mock or WeChat login.
- Bind or rebind phone number.
- Create a plan and confirm generated daily tasks.
- Generate an AI plan suggestion and commit it.
- Start, stop, complete, postpone, and makeup a task.
- Confirm auto check-in and slack reward behavior.
- Trigger recovery preview and apply after confirmation.
- Create or join a study group and send a nudge.
- Open privacy policy, user agreement, feedback, version notes, and account settings.
