# Operations And Compliance Entrypoints

## Why

Publishing a mini program requires clear user-facing policy entries, careful wording for AI/check-in/ranking features, and basic operations channels for announcements, version notes, feedback, and issue reports.

## What Changes

- Add user-facing entries for privacy policy, user agreement, feedback, and version notes.
- Add PC admin console operations entries for announcements and feedback review.
- Add compliance copy guidance for AI, reminders, rankings, and slack minutes.
- Add release review checklist for WeChat submission.

## Non-Goals

- No full customer-service chat system.
- No complex content management system.
- No legal guarantee; final policy text should be reviewed before public release.
