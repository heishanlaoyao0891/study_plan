## Why

用户在小程序开始学习后，如果登录状态被另一端覆盖，H5 重新认证只会回到打卡首页，无法主动恢复进行中的任务。计时会话实际已由服务端保存，但缺少稳定的跨端恢复入口，用户容易误以为时长从零开始。

## What Changes

- 新增当前用户进行中学习会话的查询接口，返回空值或完整的计时任务视图。
- H5 和微信小程序完成认证后优先恢复进行中的任务；未找到会话时保留原有的引导与打卡导航。
- 恢复页面以服务端累计时长和会话开始时间为准，不创建新的学习会话或重置时长。
- 增加接口隔离、登录恢复和计时累计回归覆盖。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `study-timer`: 进行中的学习任务必须可在重新认证后的任一客户端安全恢复。

## Impact

- 后端任务计时查询路由和 `study.go`。
- H5 / 微信小程序认证后的导航逻辑与 API 类型。
- 后端任务计时及前端认证导航回归测试。
