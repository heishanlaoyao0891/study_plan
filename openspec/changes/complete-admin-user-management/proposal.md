## Why

管理台的用户目录只显示昵称，无法让管理员按用户实际登录名定位账户；同时列表缺少创建入口和安全删除入口，日常账号管理需要在多个页面或直接操作数据完成。

## What Changes

- 在用户目录中分列展示登录用户名、昵称和 OpenID，并支持按任一身份标识搜索。
- 用户目录默认只展示正常账户，并提供全部、正常、封禁和已删除的明确筛选状态。
- 管理员可在用户目录直接创建普通账号，系统生成仅显示一次的随机初始密码。
- 用户可在账户设置中修改微信号式登录名或手机号登录名，每个自然月最多三次。
- 提供管理员删除普通用户的入口、确认和审计，复用既有账户删除的数据清理与匿名化规则。
- 禁止管理员删除自己或任一管理员账户。

## Capabilities

### New Capabilities

- `admin-user-management`: 管理员在单一目录中识别、引导创建和安全删除普通用户账户。

### Modified Capabilities

- `admin-config`: 管理台用户目录的身份展示、搜索与操作要求。
- `user-auth`: 账户删除的授权主体扩展到管理员，并保持既有数据删除语义。

## Impact

- 管理端用户列表、路由跳转和 API 客户端。
- 管理端用户查询、直接创建和删除 API，以及管理员审计日志。
- 后端账户删除的共享数据清理逻辑与回归测试。
- 用户端账户设置、登录名唯一性和月度修改次数账本。
