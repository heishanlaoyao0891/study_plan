# Group Study Experience

## Why

The current shared-plan support is basic. Group learning should become a concrete study-group experience with friendly joining methods, privacy boundaries, member levels, lightweight competition, and reminder actions that make mutual accountability useful.

## What Changes

- Add study group model with one active group per user.
- Add invitation code, share link, and QR-code/miniprogram-code joining methods.
- Add member list and per-member group status.
- Add group check-in dashboard with privacy boundaries.
- Add member level system based on check-ins and streaks.
- Add leaderboard by streak, study minutes, and completion rate.
- Allow members to send reminder nudges through WeChat subscription messages when permitted.

## Non-Goals

- No public discovery of groups.
- No real-money betting, deposits, or penalties.
- No chat system in this change.
- No paid invitation mechanism. Invitation code, share link, and QR/miniprogram code should use free platform capabilities, subject to WeChat API quotas.
